# 面试与项目

## D01：项目目标与证据设计

产物：目标、用户、约束、验收指标和最小 Evidence 列表。

失败案例：说明一个无法由现有证据支持的项目主张，并明确删去它。

## D02：架构表达与边界

产物：模块图、输入输出契约、失败路径和安全边界。

失败案例：回答“为什么不使用多 Agent”并说明当前单 Agent 边界。

## D03：追问与复盘

产物：三轮项目追问与证据支撑答案。

失败案例：记录一个无法回答的追问和下一步补证计划。
