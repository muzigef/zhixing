# 团队与单 Agent：真实回答质量初测

## 结论与当前边界

已完成两道开发题、六组共十二个根任务的首次真实对照。各组最终确定答案均正确，没有观察到团队的正确率收益；团队增加了调用与等待，混合团队还出现一次成员超时。**保持单 Agent 默认，团队作为实验性选项，现有结果不足以宣称回答质量更高。**

计划中的八道留出题、每组重复两次、合计 96 个根任务尚未执行。新包复测遇到 macOS 系统凭据准备等待，混合组 240 秒内未发出模型请求；随后单独 Kimi 也停在准备阶段。检测到系统 `SecurityAgent`，但尚未获得用户在系统窗口完成授权的确认。因此暂停正式留出对照，不把环境阻塞误判为模型回答能力。

## 首次开发题 V1

原始回答、成员结论、失败、计时与模型用量见[完整十二行结果](team-evaluation-pilot-20260909094200252.json)。两题分别为乘法拆分和含根式方程的增根检查，仅用于确认工程通路，不代表真实教学或复杂任务。

实际模型：Pi `gpt-5.6-terra`，DeepSeek `deepseek-v4-flash`，Kimi `kimi-k3`。同模型团队为 Pi 主模型加两个同模型成员；混合团队为 Pi 主模型加 DeepSeek、Kimi。普通组各调用一次，自检组在同一会话额外自检两次，团队通常分工、两成员、综合共四次。

| 组别 | 最终答案正确 | 整组完整完成 | 每题总耗时中位数 | 两题模型调用总数 |
| --- | ---: | ---: | ---: | ---: |
| 单 Agent · Pi | 2/2 | 2/2 | 6.11 秒 | 2 |
| 单 Agent · Pi，两次额外自检 | 2/2 | 2/2 | 19.74 秒 | 6 |
| 同模型团队 | 2/2 | 2/2 | 23.75 秒 | 8 |
| 混合模型团队 | 2/2 | 1/2 | 60.76 秒 | 8 |
| 单 Agent · DeepSeek | 2/2 | 2/2 | 3.04 秒 | 2 |
| 单 Agent · Kimi | 2/2 | 2/2 | 45.03 秒 | 2 |

以上中位数统一从原始 `durationMs` 重算，两个样本取中间两值的平均；V1 原报告的 `summary.medianMs` 曾错误地取上中位数，原文件保留用于审计，评分器已通过失败测试修复。Kimi 首次单独调用包含约 57.7 秒发送前等待，第二次共 19.16 秒；不宜将表格中的等待全部归因于模型推理。

只比较确定答案时，同模型、混合模型相对普通 Pi 都为 0 胜、2 平、0 负；把未完整完成记零分后，混合团队为 0 胜、1 平、1 负。样本太少且存在简单题的正确率上限，不能作显著性或普遍质量判断。

开发助手逐条阅读了十二个最终解释：乘法题都提供有效拆分；根式题都识别 $x\ge2$、候选值 1/4 并排除 1。团队没有补出单 Agent 缺失的关键解题步骤。部分解释对“平方不是等价变形”的表述过于绝对：在已保留两边非负条件时，平方可以保持等价；这也提醒我们，最终数值正确不等于教学表述完美。该复核没有盲法或独立人类评审，不是学习效果认证。

## 新包 V2 复测与阻塞

保留[中断记录](team-evaluation-pilot-202609091026-interrupted.json)。V2 增加受控连接准备、Pi 串行调度与明确的成员计时，参数修订发生在留出题运行之前；题目、标准答案和评分规则没有因结果调整，详见[冻结协议](../agent-team-evaluation-protocol-20260909.md)。

第一题普通 Pi、额外自检 Pi、同模型团队、DeepSeek 均完成且正确，耗时分别为 4.83、14.54、20.52、4.00 秒。混合组在系统凭据准备阶段 240.03 秒超时，模型调用数为 0。Kimi 单独调用随后仍在等待；停止评测后，其余计划行保留为取消，不能称为执行过模型对照。

停止时评测器将全部十二个计划位置落盘，未运行位置保留失败/取消；由于系统授权仍待处理，应用的退出未及时完成，在确认评测检查点已保存后终止了本次评测进程。没有删除或覆盖日常会话、凭据或工作区。此运行不能与 V1 合并计算模型质量，也不能替代留出评测。

## 完成正式质量验收所需条件

用户在 macOS 系统窗口完成这个已验收 0.10.0 包的钥匙串授权，并用产品的“测试连接”确认 Kimi 可用。不要在对话或仓库提供密码、API Key。使用同一包执行：

```bash
node desktop/scripts/evaluate-team.mjs --live --suite=pilot
node desktop/scripts/evaluate-team.mjs --live --suite=holdout
```

脚本默认使用 `~/Applications/知行.app`，可通过 `ZHIXING_DESKTOP_EXECUTABLE` 指向候选包。留出评测必须保留全部失败，比较正确率、完整率、解释要点、配对差异、首字/总时间和已报告用量。订阅不按零成本处理；六组实际算力不同，不声称严格等算力。真实学生学习效果仍需独立学前、学后和延迟复习试验。
