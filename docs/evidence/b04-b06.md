# B04–B06 实现验证记录

> 状态：已完成；本记录保留早期验证快照，完整的当前验收以 `TASKS.md` 和 `npm run verify` 为准。

## B04：长期记忆交互

新增 CLI：

```text
记住 <内容> --确认
查询记忆 [<topicId>] <问题>
忘记 <memoryId>
```

- `记住` 缺少 `--确认` 返回 `confirmation_required`；
- 记忆记录主题、来源、置信度和软删除状态；
- 默认只检索当前主题，显式主题参数可切换检索范围。

## B05：资料生命周期

新增 CLI：

```text
资料删除预览 <topicId> <documentId>
删除资料 <topicId> <documentId> --确认
备份数据库
```

删除前返回文件名和受影响 Chunk 数。确认删除后，本地原始资料目录、SQLite documents/chunks、FTS 索引同步清理。未确认删除被拒绝。数据库备份使用 `better-sqlite3.backup()`，不依赖文件复制时机。

## B06：Codex Provider adapter

新增 `CodexCliClient`：

- 历史行为：先检查 `ZHIXING_ALLOW_LIVE_PROVIDER=1`，默认拒绝。当前策略见 `SECURITY.md`。
- 只以非 shell argv 调用官方 `codex exec`；
- 使用 `--sandbox read-only`、`--ephemeral`、`--skip-git-repo-check`、`--ignore-rules`；
- 不读取、保存或导出任何登录凭证；
- 支持 AbortSignal、Mock runner 和 `provider_unavailable` 错误。

没有执行真实 Codex smoke，也没有把用户资料发送给外部 Provider。
