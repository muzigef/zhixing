# 教学效果验证：实现与验收

日期：2026-09-07。基于 `8bc5124` 完成开发与验收，本轮没有重新打包安装器。后续 Git 提交与发布状态以仓库历史为准。使用入口与评估边界见[学习效果验证](../learning-outcomes.md)。

## 完成的开发

- 新增 `LearningOutcomeStore` 与版本化题库：Agent 执行边界、RAG 证据判断，各 3 套情境卷、每套 3 题；随机排列学前、学后和延迟阶段用卷。
- SQLite 持久化阶段、真实用户提交、帮助声明、文字解释、题卷 ID、时间及成绩。选择题由程序评分，文字解释标为待人工复核；未知选择按未答对计，不强迫猜测。
- 学习对话关联真实会话。两种方式使用相同目标、模型通道和篇幅规范，知行方式增加教学提示；都不自动引入检查数据、旧历史、学习材料或工具。
- 记录每轮实际 Provider、模型、思考档位、篇幅；学后检查要求至少一个实际完成回答和已处理的队列。`lesson.durationMs` 仅为累计模型生成耗时，不代表学习者的学习时长。
- 学后提交后满 72 小时才开放延迟检查，应用无提前完成的产品开关；最终显示延迟卷解析。正常关闭和重新打开保留当前阶段。
- 独立成对成绩按条件分组。演示、未知/变化的模型、借助帮助、重复练习单列。未复习不记零；学后已完成但提前结束验证的合格成绩仍计入，避免只统计完成所有阶段的人。
- 桌面导出包含本人作答；本地 `eval:learning` 汇总按验证 ID 去重，拒绝版本、主题、已有作答和分数冲突，不复制原始解释到汇总。
- 全量备份恢复重映射验证关联的会话 ID；同时修复恢复工作区路径未取 canonical path 导致的 workspace ID 不一致。

新增主要文件：`src/outcome-contracts.ts`、`src/outcome-bank.ts`、`src/learning-outcomes.ts`、`src/outcome-report.ts`、`desktop/renderer/outcome-panel.tsx` 及两个 CLI 诊断/汇总脚本。既有 Service、IPC、学习面板、备份和文档已接入。

## 真实模型接入

命令：

```bash
npx tsx scripts/check-learning-outcomes.ts --live --output=docs/evidence/learning-outcomes-live-20260907.json
```

使用临时合成工作区和合成作答，Pi 自行处理认证。两种方式均使用 `gpt-5.6-terra`、`balanced`、`adaptive`，各一次请求、零工具调用：

| 方式 | 首字 | 完整回答 | 流程 |
| --- | --- | --- | --- |
| 同模型直接聊天 | 6.209 秒 | 13.641 秒 | completed → post |
| 知行引导教学 | 3.943 秒 | 7.619 秒 | completed → post |

安全记录含原答和模型 usage，见[真实接入 JSON](learning-outcomes-live-20260907.json)。知行方式的本次答案在讲解后追加了新情境问题；这一次行为观察不能证明教学效果或速度优于直接聊天。首次请求与后续请求的启动、网络及服务端等待也可能不同。

## 未验证和下一步

- 尚无真实学习者前后测、实际等待 3 天的复习结果、独立人工评分、题卷难度校准或因果效果结论。时钟边界由可控时钟测试验证，不能冒充真人三天学习。
- 文字解释和新例子保留待复核，当前应用没有人工评分录入；试用复核规则见使用指南。
- 独立作答是用户自报，应用不能检查其他窗口、设备或外部帮助。题库范围小，满分不等于全面掌握。
- 本轮真实请求只使用 Pi；DeepSeek 使用既有共享通道与 UI/自动回归，未重跑 DeepSeek 真实教学请求。
- 未重新构建安装包或验收 Windows/Intel/签名/公证/远端 CI。当前源码可通过 `npm run desktop` 体验。
- 下一步由真实学习者使用、复核解释并校准题卷；不凭测试数量宣布教学效果提高。
