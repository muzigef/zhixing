# 回答的来源与支持检查

检索引用包含文档、页码或锚点、片段 ID 和原文内容哈希。打开新回答的来源时，会对照索引中的实际片段字节；内容改变会提示重新检索，历史回答不自动改写。旧引用没有哈希时继续按原位置读取，不伪称已经完成版本核对。

格式检查与证据支持检查分别记录。支持检查针对当前取得的原文片段：

- 精确比例、金额和带单位测量是否在对应引用中出现；量化结论没有紧邻引用时提示缺少依据。
- “保证”“一定”等措辞是否超出材料提供的条件。
- 引号内长句是否能在原文中找到，以及同名引用是否指向多个文档。

资料问答发现这些问题时返回 `insufficient_evidence`。共享 Agent 工具对话最多自动修正一次，仍有问题就保留检查提示并标记受阻。修正前的答案留在执行日志，用户对话中的阶段项显示检查状态；不是把不受支持的旧结论作为完成答案保存。直接文本 Provider 不支持续轮修正时显示诊断，不自动切换 Provider。

检查记录包含所检查的回答片段和来源的内容哈希、检索片段字符范围；原文可从桌面打开。不存模型内部推理。字符范围从当前检索片段开头计数，不冒充整个 PDF 页面的版面坐标。

这些是确定性的风险检查，不是完整语义蕴含判定。同一数字描述不同对象、复杂否定、隐含条件或材料本身错误仍可能漏检；计算推导不能仅因数字曾在原文出现就判为正确。数学、代码执行、逐句内容审查和独立人工评估分别需要相应证据。通过规则检查时界面只显示“规则未发现问题”。
