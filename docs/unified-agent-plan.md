# 桌面与 CLI 策略统一

> 历史计划或版本记录：下文保留当时的设计、范围及验证结果，不是当前功能清单或新的开发指令。现行实现、已完成的后续改动与待验收项见 [当前状态](current-status.md) 和 [文档导航](README.md)。

基线：`32decd4`。2026-09-08 用户要求从架构保证两个入口使用完全相同的 Agent 策略。

一致性契约：同一工作区状态、完整会话、业务请求、授权、模型及配置，两个入口使用相同的上下文构建、长期记忆选择、教学动作、摘要、工具目录与执行恢复规则。入口只转换输入、配置和输出；模式差异必须是共享业务契约的一部分，不能依赖 desktop/CLI 身份。模型输出的随机性不作为策略等价标准。

| 切片 | 范围 | 验收 | 状态 |
| --- | --- | --- | --- |
| U01 | 共享学习上下文和教学状态 | 画像、显式记忆、作答、更正/撤回、教学状态有统一来源及授权；普通/教学会话共用历史与摘要 | 已完成 |
| U02 | 移除入口自定义调用旁路 | CLI 不构造最终 prompt、选择模型历史、独立分类教学输入；共享业务请求处理问答、教学与计划 | 已完成 |
| U03 | Provider 与配置适配 | 主力 Pi/DeepSeek 使用相同模型协议和能力；入口不能改变预算、授权或回读策略 | 已完成 |
| U04 | 架构约束与交付 | 静态依赖门禁、真实 CLI 对照、长对话/摘要/恢复/撤权回归、完整 verify、五组开发与实包 UI、文档和版本更新 | 已完成 |

保留旧历史兼容读取与恢复证据，不让六轮兼容投影参与模型上下文决策。每个切片先复现边界再实现，定向测试后运行完整 verify。使用合成临时工作区；不读取凭据或直接修改用户数据。不以既有 553 项测试证明新的一致性要求通过。

最终状态：U01–U04 已完成。567 项测试、开发与实包各五组 UI、两套生产审计与 DMG 内容核对通过；详见 [执行证据](evidence/unified-agent.md)。安装包为 0.7.0；本轮不把历史真实模型请求记为重新验证。
