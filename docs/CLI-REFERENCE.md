# CLI 参考

统一入口：`npm run start -- '<命令>' [--topic <topicId>]`；`npm run start --` 后不要再额外加入第二个 `--`。交互模式：`npm run repl`。

下列命令在 CLI/REPL 中使用，桌面输入框当前只提供模型对话，不执行这些学习管理命令。配置与数据目录见[配置说明](CONFIGURATION.md)。

| 分类 | 命令 |
| --- | --- |
| 学习 | `创建主题 <topicId> <标题>`、`主题列表`、`学习 <主题>`、`开始第 N 天`、`开始任务`、`继续`、`下一步`、`进度`、`主题概览`、`全部进度`、`读源码 DNN`。真实 tutor 下，开始学习会进入“深度讲解 → 答疑确认 → 练习测验 → 实验与 Review”的阶段流程。 |
| 证据 Review | `提交证据 DNN <implementation/testOutput/failureCase/reflection/testScript> <实际文本>` 保存产物；`证据列表 DNN` 查看；`检查 DNN` 校验文件哈希与计划要求。旧布尔标记不计入证据，完整性分数不是能力评分。 |
| 本地验证 | `运行测试 DNN` 在 macOS 受限环境运行已提交 JS 实现和 node:test 脚本，10 秒超时；其他平台显示 unavailable。上传的测试报告标为未复跑。 |

| 自然交互 | 默认开启自然交互；本地支持“今天学什么”→`下一步`、“看进度”→`进度`、“当前在学习的是哪个主题”→当前主题。普通知识问题直接回答；明确的学习计划或管理请求才追问必要信息或生成受校验的草案；看到草案后回复“就按这个来”“好，执行吧”或“直接运行”可执行已实现的白名单动作。创建计划时，画像保存、定制课程生成和启用在这一次授权中完成，不要求复制 version。导入、删除、恢复或模型切换仍要求“直接运行 --确认”或“我确认执行”；API Key 配置仍必须走隐藏输入。绝不执行模型生成的 Shell 命令。进入学习后可直接追问、要例子或代码；说“调整学习计划”等明确管理请求时生成草案，教学检查点保留。即使有待执行草案，也可继续提问或要求练习。修改草案失败会撤销旧草案，防止误执行旧参数。`自然交互关闭` 可关闭；`自然交互开启 --允许外发` 重新开启（`--允许外发` 为兼容文本）；另起对话使用 `/new`；`理解命令 <自然语言> --允许外发` 仍可生成经校验的命令草案。 |

| 模型与同步 | `模型添加 api-key deepseek-api`、`模型列表`、`模型状态`、`诊断`、`模型切换 <tutor\|reviewer\|lab> <mock\|deepseek-api\|codex-cli\|pi-codex> --确认`、`启动同步服务 [port]` |

CLI 初始角色路由均为 `mock`，保存过的本地路由优先。真实 Provider 在已配置时默认允许调用；`资料问答` 会把检索到的证据发送给当前 tutor。`ZHIXING_ALLOW_LIVE_PROVIDER=0` 禁止真实请求，但不修改路由，也不保证调用自动回退到 mock。自然问答、教学和学习助手失败不会自动换模型；可显式切到 `mock` 使用本地学习流程，或检查真实 Provider 后重试。

用户直接输入 `导入资料 <topicId>/<文件>` 已构成显式导入请求，不另加 `--确认`；模型草案中的导入则需“直接运行 --确认”。删除、恢复、模型切换与长期记忆写入要求命令级确认。`忘记 <memoryId>` 按当前主题直接删除指定记忆，当前命令没有预览或附加确认参数。备份预览/恢复的 `<file>` 是 `db/backups/` 内的 `.sqlite` 文件名，不接受任意路径。主题 ID 的核心 schema 允许小写字母或数字开头，其余为小写字母、数字、连字符；如 `3dgs`、`gaussian-splatting` 均有效。

画像、个性化计划、资料概览和 Skill 草案不调用模型；它们离线可用，草案只在用户启用后影响活动计划或 Skill 目录。设置画像会立即保存当前主题偏好。所有 Day 的完成仍由证据 Review 决定；“提醒设置”只保存本地时间计划，不会启动后台通知。

`tutor` 是资料问答、学习建议、自然交互和模型讲解使用的角色；`reviewer` 和 `lab` 是可独立配置的预留角色。切换路由会写入本地设置。`codex-cli` 使用官方 `codex exec --json` 的只读、临时调用并忽略用户配置；知行只渲染其 assistant 文本，不读取或保存登录凭据，也不会执行模型建议的 Shell 命令。`pi-codex` 则从 Pi 配置选择模型，经受控 Pi 子进程调用。交互终端显示“思考中…（Ctrl-C 停止）”，回答分段流式显示；非终端输出不添加模型状态和颜色。两个 Codex 适配器在 CLI 中的调用上限均为 150 秒，DeepSeek 为 60 秒。

`诊断` 输出当前主题、Provider 健康状态、tutor 路由、持久化教学检查点、画像、记忆、资料、提醒和脱敏最近运行摘要，用于定位恢复或模型调用问题。

`模型状态` 的健康检查不是完整连通测试：DeepSeek 检查 Keychain 中是否有 Key，Pi 检查模型偏好，Codex CLI 常显示 `unknown`。实际认证、余额和服务可用性仍在发送时判断。

学习助手默认上限：6 个模型回合、32 次工具请求、10,000 个流事件、64,000 字符输出、128,000 字符上下文估算和 180 秒总时限。资料工具每次最多返回 3 条证据。超限会停止；断流或超时的部分文本会明确标记未完成。

## 交互与输出

| 用途 | 输入与行为 |
| --- | --- |
| 自由问答 | `解释注意力`、`举个例子`、`用代码说明`、`只要结论`；无需先建画像或计划。 |
| 练习 | `开始练习`、`来一道题`、`出两道题`、`给我一道应用题`；默认一题，明确数量和题型时按用户要求。 |
| 提示与答案 | `不要给答案，只给提示`、`给答案`、`给出参考解析`；不会记作实际作答。 |

| 回答风格 | `/style concise`、`/style balanced`、`/style detailed`；也支持 `回答风格 简洁/适中/详细`。无参数查看当前风格，按主题保存，重启保留。 |
| 帮助与状态 | `/help`、`帮助`；`/status`、`当前状态`、`/queue` 在回答过程中也即时响应，显示活动、耗时和排队数量。无模型调用。 |

| 中途调整 | `等等，换个例子`、`等一下，用代码解释`、`/steer <新要求>` 停止当前文本生成，再结合原问题与部分回答继续；写操作期间按顺序排队。 |

| 对话恢复 | `/new` 或 `新对话` 开启新聊天；`/resume` 列出当前主题最近 20 个对话，`/resume <编号>` 恢复。原对话保留。 |

| 计划管理 | `/plan <需求>` 明确进入计划管理；`/cancel-plan` 或 `取消草案` 撤销待执行草案。 |
| 停止与退出 | `停止`、`停一下`、`暂停回答`、`/stop` 或 Ctrl-C 停止当前回答并继续输入；`/exit`、`退出`、`exit` 或 `quit` 退出。 |

本轮用户指定的篇幅、语言、代码或表格格式优先于保存的风格；不强制字数、不在每次答疑后追加固定口令。明确的练习、参考答案和澄清请求不额外调用分类模型；仅模糊的练习作答需要分类与原文验证。

TTY 显示标题、列表和强调；重定向输出、`NO_COLOR=1` 或 `TERM=dumb` 保留 Markdown。代码与数学块不改写；终端不排版 LaTeX，回答约定要求公式后附中文解释。终端控制序列会被移除，防止污染输出。普通短段落约每 80 毫秒刷新，代码/公式分隔符等行等待换行以免错误解析，超过 1,024 字符的长行仍会分段。输入草稿时暂存新增显示，提交或取消输入后释放，避免回答覆盖输入。此界面使用行式终端，不是固定底部输入框的全屏 TUI。

资料问答的引用必须与检索到的文档和页码/锚点完整匹配；断流内容明确标记未完成。此校验保证引用位置合法，不能替代逐句事实核验。

普通问答和工具助手自动保存当前主题最近 6 轮对话，每轮用户输入和回答各最多 8,000 字符，超长内容标记截断，并另行保存最多 4,000 字符的最初目标。重启自动恢复，正常取消保存部分回答；强制结束进程可能丢失尚未保存的流内容。`/new` 不删除教学检查点，`开始任务` 或 `开始第 N 天` 可回到教学。恢复旧聊天不会倒退教学检查点或学习进度。计划草案仍只在当前进程内有效，不会自动重放写操作。

## 模型配置与本地同步

使用 Pi 已配置的 Codex：`模型切换 tutor pi-codex --确认`。默认 Provider、模型与推理强度从 Pi 设置读取，认证由 Pi 处理；下一轮会重新读取模型偏好。需要 Pi 中配置 `openai-codex` 并完成登录，不需要向知行另填 OpenAI API Key。CLI 的项目级 Pi 偏好优先于全局偏好，桌面使用独立的 `runtime/` 项目目录。接入详情见[配置说明](CONFIGURATION.md#pi-codex-接入)。

使用 DeepSeek：先执行 `模型添加 api-key deepseek-api`，按隐藏输入提示配置，再执行 `模型切换 tutor deepseek-api --确认`。CLI 当前通过 macOS Keychain 保存 Key；桌面另有系统加密的设置入口。普通概念问答可使用任一文本 Provider；`学习助手` 的连续工具调用当前仅由 DeepSeek 适配器支持。

`启动同步服务` 在当前 CLI 进程中保持服务；省略端口或填 `0` 时动态分配，仅监听 `127.0.0.1`。`GET /topics/<topicId>/progress` 返回进度 JSON；`GET /topics/<topicId>/events` 先发送 `ready`，在受控 `run()` 成功返回后发送 `progress` 变更通知（`topicId`、`command`、`at`）。通知不是完整进度快照，客户端需再次读取进度接口。主题范围在服务启动时固定；该接口不是云同步，桌面当前没有接入。

当前 HTTP 路由只接受字母开头的 topic ID，与核心 schema 允许数字开头不一致；例如核心命令可使用 `3dgs`，对应同步 URL 仍会返回 404。这是同步入口的已知缺口。
