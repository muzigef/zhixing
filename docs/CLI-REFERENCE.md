# CLI 参考

统一入口：`npm run start -- '<命令>' [--topic <topicId>]`；`npm run start --` 后不要再额外加入第二个 `--`。交互模式：`npm run repl`。

| 分类 | 命令 |
| --- | --- |
| 学习 | `主题列表`、`学习 <主题>`、`开始第 N 天`、`继续`、`进度`、`全部进度`、`读源码 DNN` |
| 资料 | `导入资料 <topicId>/<文件>`、`资料库`、`资料概览`、`查询资料 [topicId] <问题>`、`资料问答 <问题> --允许外发` |
| 画像与计划 | `设置学习画像 <目标> --水平 <水平> --每天 <分钟> --周期 <天数>`、`学习画像`、`生成个性化计划`、`启用个性化计划 <version>`、`调整计划 <分钟>`、`启用计划 <version>`、`复习计划` |
| Skill | `生成技能草案 <kebab-case 名称>`、`技能草案列表`、`读取技能草案 <名称>`、`启用技能草案 <名称>`、`技能列表 [topicId]`、`读取技能 <名称>` |
| 建议 | `学习建议`（本地）、`学习建议 --允许外发`（使用当前 tutor 路由；仅发送画像与资料名称） |
| 记忆 | `记住 <内容> --确认`、`查询记忆 [topicId] <问题>`、`全局查询记忆 <问题>`、`忘记 <memoryId>` |
| 生命周期 | `资料删除预览 <topicId> <documentId>`、`删除资料 <topicId> <documentId> --确认`、`备份数据库`、`备份预览 <file>`、`恢复数据库 <file> --确认` |
| 模型与同步 | `模型添加 api-key deepseek-api`、`模型列表`、`模型状态`、`模型切换 <tutor|reviewer|lab> <mock|deepseek-api|codex-cli>`、`启动同步服务 [port]` |

`资料问答` 未带 `--允许外发` 时只返回本地检索证据。删除、恢复与长期记忆写入都要求命令级确认。

画像、个性化计划、资料概览和 Skill 草案不调用模型；它们离线可用，且只在用户显式启用后影响当前主题的活动计划或 Skill 目录。所有 Day 的完成仍由原有证据 Review 决定。

`tutor` 是资料问答与学习建议使用的角色；`reviewer` 和 `lab` 是可独立配置的预留角色。切换路由会写入本地设置，但真实调用仍要求终端设置 `ZHIXING_ALLOW_LIVE_PROVIDER=1`。
