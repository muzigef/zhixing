# CLI 参考

统一入口：`npm run start -- '<命令>' [--topic <topicId>]`；`npm run start --` 后不要再额外加入第二个 `--`。交互模式：`npm run repl`。

| 分类 | 命令 |
| --- | --- |
| 学习 | `创建主题 <topicId> <标题>`、`主题列表`、`学习 <主题>`、`开始第 N 天`、`开始任务`、`继续`、`下一步`、`进度`、`主题概览`、`全部进度`、`读源码 DNN`。真实 tutor 下，开始学习会进入“深度讲解 → 答疑确认 → 练习测验 → 实验与 Review”的阶段流程。 |
| 资料 | `导入资料 <topicId>/<文件>`、`资料库`、`资料概览`、`查询资料 [topicId] <问题>`、`资料问答 <问题>` |
| 画像与计划 | `设置学习画像 <目标> --水平 <水平> --每天 <分钟> --周期 <天数>`、`学习画像`、`生成个性化计划`、`启用个性化计划 <version> --确认`、`生成定制课程`、`启用定制课程 <version> --确认`、`调整计划 <分钟>`、`启用计划 <version> --确认`、`复习计划`、`提醒设置 HH:MM` |
| Skill | `生成技能草案 <kebab-case 名称>`、`技能草案列表`、`读取技能草案 <名称>`、`启用技能草案 <名称> --确认`、`技能列表 [topicId]`、`读取技能 <名称>` |
| 建议 | `学习建议`（使用当前 tutor 路由；仅发送画像与资料名称；`--允许外发` 为兼容语法） |
| 模糊命令 | 默认开启自然交互；本地支持“今天学什么”→`下一步`、“看进度”→`进度`、“当前在学习的是哪个主题”→当前主题。模型会追问必要信息，或生成受校验的待执行草案；回复“直接运行”可执行已实现的白名单动作。创建计划时，画像保存、定制课程生成和启用在这一次授权中完成，不要求复制 version。导入、删除、恢复或模型切换仍要求“直接运行 --确认”或“我确认执行”；API Key 配置仍必须走隐藏输入。绝不执行模型生成的 Shell 命令。进入学习后，非命令回答会进入教师追问；说“调整计划”等管理请求会退出教学对话，转回协调器处理。`自然交互关闭` 可关闭；`自然交互开启 --允许外发` 重新开启并清空本轮对话（`--允许外发` 为兼容文本）；`理解命令 <自然语言> --允许外发` 仍可生成经校验的命令草案。 |
| 记忆 | `记住 <内容> --确认`、`查询记忆 [topicId] <问题>`、`全局查询记忆 <问题>`、`忘记 <memoryId>` |
| 生命周期 | `资料删除预览 <topicId> <documentId>`、`删除资料 <topicId> <documentId> --确认`、`备份数据库`、`备份预览 <file>`、`恢复数据库 <file> --确认` |
| 模型与同步 | `模型添加 api-key deepseek-api`、`模型列表`、`模型状态`、`诊断`、`模型切换 <tutor|reviewer|lab> <mock|deepseek-api|codex-cli> --确认`、`启动同步服务 [port]` |

默认允许已配置的真实 Provider；`资料问答` 会把检索到的证据发送给当前 tutor。可用 `ZHIXING_ALLOW_LIVE_PROVIDER=0` 强制本地模式。删除、恢复与长期记忆写入仍要求命令级确认。

画像、个性化计划、资料概览和 Skill 草案不调用模型；它们离线可用，且只在用户显式启用后影响当前主题的活动计划或 Skill 目录。所有 Day 的完成仍由原有证据 Review 决定。

`tutor` 是资料问答、学习建议、自然交互和模型讲解使用的角色；`reviewer` 和 `lab` 是可独立配置的预留角色。切换路由会写入本地设置。自然交互中，明确选择的 Provider 失败会显示真实错误，不会悄悄改由 Mock 回答。Codex 使用官方 `codex exec --json` 的只读、临时、无审批调用；知行只渲染其中的 assistant 文本增量，不读取或保存登录凭据，也不会执行模型建议的 Shell 命令。REPL 会先显示“正在由…处理；可按 Ctrl-C 取消…”。Codex 调用上限为 150 秒，DeepSeek SSE 调用上限为 60 秒。

`诊断` 输出当前主题、Provider 健康状态、tutor 路由、持久化教学检查点、画像、记忆、资料、提醒和脱敏最近运行摘要，用于定位恢复或模型调用问题。
