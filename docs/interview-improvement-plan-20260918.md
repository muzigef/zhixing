## 验收原则

- 每个行为切片先添加失败或边界用例，再实现，定向测试之后运行 `CI=1 npm run verify`；桌面行为额外跑七组 UI。
- 不把合成模型评分说成真实质量提升，不把研究工具说成已有学习者收益，不把本地签名说成 Developer ID 公证。
- 真实参与者、独立评阅、三天延迟随访及正式发行证书属于外部条件；完成对应工程后分别记录可复现验证与待验收条件。
- 不读取真实密钥/认证文件、不外发用户资料。真实模型验收只经既有产品受控接口并使用公开固定题与既定预算。
- 失败证据保留；原有平台隔离与副作用恢复边界不降低。
