# 知行项目面试准备

这套材料面向中高级 Agent 应用开发与架构岗位，按项目源码、真实验证记录和公开招聘要求整理。先理解与演练，再用自己的语言回答；它不是公司实际面试题泄露，也不代替现场编程练习。

## 阅读顺序

1. [岗位要求与项目匹配](job-market.md)：11 个相关岗位样本、能力矩阵、项目优势与缺口、14 天准备安排。
2. [问题与参考答案](question-bank.md)：按领域组织，包含口述答案、分析、取舍、代码依据和追问。
3. [系统设计与项目讲解](system-design.md)：需求拆解、容量假设、架构、故障恢复、渐进演进和项目表达。
4. [来源与证据边界](sources.md)：招聘原文、页面限制、项目事实与技术资料的区别。

若时间有限，先练习通用接入、Agent loop、工具权限、长对话、执行恢复、多模型团队、评测公平性和性能预算，再进入云端系统设计。基础薄弱时先补数据结构、异步调用、HTTP/SSE、事务、LLM token 与采样概念。

## 一次模拟面试

| 时间 | 内容 | 合格表现 |
| --- | --- | --- |
| 0–5 分钟 | 项目介绍与架构图 | 说明学习目标、模块化单体、共享内核与当前能力 |
| 5–20 分钟 | 选4道核心题追问 | 能从契约走到源码/测试，不只说框架名称 |
| 20–35 分钟 | 选1个故障或系统设计案例 | 先澄清假设，列出状态、失败与替代方案 |
| 35–45 分钟 | 评测与 trade-off | 不混淆工程测试、模型质量和教学收益 |
| 45–60 分钟 | 小型编码或最小复现 | 自己实现、解释失败测试，并说明复杂度与限制 |

## 项目表达底线

- 截至本文基线，最新已推送代码是 `60570bc`，桌面包声明0.11.0；不代表用户已安装最新版。
- 814 项测试与七组本机实包 UI 是工程验证；三家连接是可用性验证；四道固定题20次运行是小样本模型对照；真实教学收益仍待研究。
- 最新远端 CI 的团队 UI 失败，以及 CLI/桌面输入上限差异，属于[当前状态](../current-status.md)记录的真实限制，应能坦诚解释下一步如何验证。
- 云端多租户、分布式执行、生产 SLO、微调/强化学习和 GPU 推理优化属于系统设计扩展或补充学习，不能包装为知行已经具备的成果。
- 对 AI 辅助开发的使用如实说明，并能独立复现和解释关键路径。
