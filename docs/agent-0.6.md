## 使用变化

| 使用场景 | 当前行为 |
| --- | --- |
| 长任务暂停或外部写入结果未知 | 在「任务详情」查看暂停原因、累计用量、旧计划与修订；只读核对服务结果，也可记录用户观察或结束。未知副作用不会自动重放。 |
| 授权当前会话 | 学习资料、当前项目、已配置外部工具分别选择。具体写入可逐次批准或记住限定操作；撤回后未执行的旧批准失效。项目切换、MCP 配置变化需重新授权。 |
| 实践修改 | 修改前快照、带上下文的精确差异、唯一片段替换、最多十文件批量校验与恢复预览。文件改变使旧测试失效，重新测试后才可保存 Git 检查点。 |
| Python 练习 | 可创建 Python 项目，使用本机受验证的 Python 标准库运行 `unittest`；与 JS 共用十秒预算和 macOS 沙箱，不安装第三方包。环境不可用时明确显示。 |
| 大工具结果与长历史 | 大结果保留状态并提供有界原文续读；历史和执行记录按版本分页读取，裁剪模型上下文不删除原记录。 |
| 很多会话与长对话 | 会话元数据索引、每页四十条、全历史标题搜索；消息先呈现末四十条，可加载更早消息；增量事件合并并保留结束顺序。 |
| 模型与检索诊断 | 可设置上下文和输出预留；usage 校准估算而不扩大配额。语义检索不可用时明确显示关键词降级。当前图片输入明确不支持。 |
| Skill 使用 | 显示版本、内容哈希、适用条件及关联评测。刷新失败时明确标为旧缓存；关联测试不表示已经通过，也不授予工具权限。 |
| 教学反馈 | 四主题、二十四知识点关联实际作答和帮助方式。根据误解/独立表现选择反馈，尊重直接答案请求，纠正或撤回后重新计算。 |
| 再次课程检查 | 同一知识点交替使用两组不同情境题，共四十八题。题库版本和题卷随下发及结果保存，旧作答按原题评分；难度尚未校准。 |
| 引用回答 | 核对来源版本及片段，对无依据数值、指标错配和部分过强结论给出诊断；最多一次修复。该确定性检查不等于全面语义事实核验。 |
| 学习效果试验 | 可选「完整产品能力」或旧「仅提示方式」。完整产品组走实际教学和获授权工具，直接聊天组隔离这些能力；检查作答不自动进入模型上下文。 |

## 核心模块

`AgentService` 管理会话与任务入口，`collectInvocation` 持有规范模型/工具转录，`ToolHarness` 从同一可执行 Zod v4 schema 派生公开工具定义。MCP 保留远端 JSON Schema，在独立工作线程校验。Pi worker 只生成模型事件，执行权留在应用。

`TaskContinuity`、`AgentExecutionStore` 保存计划修订、未知结果与累计用量；`AgentPermissions` 将访问绑定到实际项目 ID / MCP 配置版本。`PracticeProjects` 用修改日志、目录切换和持久回执处理失败及进程重启，恢复保留 Git 历史。

`TeachingPolicy` 使用 `LearningObservations` 和版本化知识点证据；`AssessmentStore` 保存下发题目，`LearningOutcomeStore` 独立保存效果试验。后者没有模型工具接口，不混入通常的学习上下文。

## 数据与构建兼容

- 会话写入格式为 **v5**，支持读取 v1–v4；读取不改写，首次保存前保留 `.vN.bak`。旧版拒绝 v5，避免丢失细粒度权限、试验协议和版本证据。
- SQLite 迁移标记为 **5**；旧二进制拒绝新数据库。升级前可通过应用导出完整备份；回退需使用升级前备份，不能直接用旧应用打开新数据。
- 完整备份在新工作区恢复，清除访问/记住的操作、MCP 启用状态、项目选择和租约。操作未知的事实、题目作答及原始执行记录保留。
- 每次桌面构建写入 `runtime/build-provenance.json`。内容哈希覆盖核心、renderer、worker、脚本、两套锁文件、内置 Skill、主题和评测集；不扫描凭据或用户工作区。manifest 记录文件哈希、Git 状态、构建时间与环境，安装器另计算 SHA-256。
- 真实质量报告、完整产品试验绑定构建来源；效果汇总按协议、题库、模型设置、预算及构建分组，缺少或变化的构建不混入完整产品对照。源码快照及哈希不是发布签名或第三方认证。

原有运行和保存配额没有提高。五分钟 MCP 目录缓存不等于常驻进程池；会话索引可重建，不是第二套历史正文。真实学习者、三天延迟复习、独立人工评价、指定第三方 MCP、Windows/Intel 实机和 Apple 签名公证分别保留为外部验收。
