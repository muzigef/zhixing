# 会话授权范围

桌面新对话提供三个独立开关：学习上下文（进度、知识检查记录与当前主题资料）、当前实践项目、当前配置的外部工具。普通对话默认关闭。开启项目前先选择项目；开启外部工具前先配置并启用服务。授权限定当前主题和会话，不会转移到新选择的项目或新 MCP 配置。

“学习操作”下拉框只授权学习产物保存和课程实验。项目修改与外部写入仍需对应操作卡批准。“允许这一次”只处理当前调用；“本会话允许”记住卡片显示的范围：项目编辑绑定具体文件和工具，外部调用绑定完整参数及工具版本，学习操作绑定学习日和产物类型。换文件、换工具、换主题或改变外部参数需要新批准。最多保留 64 条操作授权。

撤回对应访问开关会同时撤回该类记住的操作；也可单独点击“撤回已记住的操作授权”。运行中先停止任务，再撤回。开关保存失败会恢复原值并显示错误。配置或项目改变后，核对范围并关闭再开启相应开关，不沿用旧授权。

排队请求只能保持或缩小当前授权：排队时的“仅查看”仍生效，撤回后旧队列也不能重新开放访问。恢复执行记录时，原来所需的资料、项目和外部配置必须仍获授权；不满足时需恢复同一范围或新建任务。已发出的消息和已有记录保留，撤回不会删除历史或撤销已经发生的外部效果。

分支和备份恢复不继承访问或操作授权。人工报告外部操作成功只是一条观察，再次执行仍需新批准。旧版会话首次发送时将原“学习上下文”授权按当时已选项目和已启用服务绑定为固定范围，以保留兼容性；新版桌面显式发送三个开关。

CLI `/agent` 按需组合 `--允许外发`、`--允许项目`、`--允许外部`，分别对应上述三项；例如 `/agent 检查当前项目 --允许项目`。`/permissions` 查看范围，`/permissions --撤回全部` 全部撤回，`/permissions --允许项目 --撤回操作` 仅保留项目访问并清除记住的写入授权。CLI 原有受控课程命令及直接用户操作保持其独立授权契约。

实现与验证：[`bindPermissions` / `writePermission`](../src/agent-permissions.ts)、[`AgentService`](../src/agent-service.ts)和[权限恢复测试](../tests/agent-permissions.test.ts)。团队分享开关只能在现有访问授权内收窄范围，不能授予成员写入；官方仅上下文执行器也不会因开启开关而获得工具能力。
