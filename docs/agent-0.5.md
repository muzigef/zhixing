# 0.5 使用与升级

0.5.0 的架构继续围绕共享 Agent 内核、连续任务、受控工具和真实验证改进；产品目标仍是学习、实践与反馈。没有将代码执行成功或模型回答完整解释成学习者已掌握。

## 这次可用的改进

| 能力 | 用户可见行为 |
| --- | --- |
| 上下文预算 | 长对话保留当前请求、目标和明确纠正；历史裁剪与估算用量可诊断，本地原文保留 |
| 按需工具与思考档位 | 工具按任务发现；设置可选自动、快速、平衡、深入，手动档位始终优先 |
| 输出与续写 | 流式增量合并显示，停止保留末段；控制完全重复的续写长前缀，诊断公式、代码、引用与段落问题 |
| 质量评测 | 可运行合成题、导入署名评分、复算分模型统计；未完成、未尝试与未评分分别展示 |
| 学习观察 | 课程检查记录原始作答、帮助方式和错因，跨会话可查、可注释、可撤回 |
| 解释复核 | 学习效果验证结束后录入署名解释复核，保留修订来源；不修改选择题得分 |
| 有界并行 | 仅明确纯只读且独立的学习查询最多并行两个，写入和交互继续有序执行 |
| 外部工具 | 按主题配置受控 stdio MCP 服务、允许工具及风险，默认关闭；调用仍受授权和取消约束 |
| 项目实践 | 创建独立项目或导入文本副本，预览差异、保存文件、运行实际测试并保存本地 Git 检查点 |

使用 [MCP 指南](mcp-tools.md)、[实践项目指南](practice-projects.md)、[质量评测指南](agent-quality-evaluation.md) 和[学习效果验证](learning-outcomes.md)查看具体操作。

自动思考档位是程序根据请求长度、任务类型和执行方式选择的启发式策略，不是模型自评能力。按需发现可减少无关 schema，也可能多一次模型往返。普通任务最多 6 个模型回合，用户已连接项目时最多 12 个；总计仍受 32 次工具调用和 180 秒约束。

回答检查只覆盖可明确验证的格式、引用标记和重复边界；一次修复仍不满足段落/续写约束时明确停止。它不保证事实、推导或语义正确，已知真实模型残余问题保留在验收记录中。

## 学习观察如何使用

在课程的独立知识检查中填写真实作答方式并提交，程序才产生观察。面板保留作答来源、原始复盘和日期；注释、撤回或恢复均保留修订历史。允许当前主题上下文后，普通教学对话最多参考三条相关观察；没有主题授权、不同主题或专门的学习效果对照会话不会获得这些记录。

借助提示/答案完成时安排较早复习；独立作答与旧版未知帮助状态分别比较。应用不能验证自报身份或帮助方式，观察是后续教学的依据之一，不是自动诊断或掌握认证。

## 兼容、安装与回退边界

新会话保存为 **v4**，包含项目/MCP 审批预览和最多 12 轮计时。读取 v1/v2/v3 不改写文件，首次保存前保留 `.v1.bak`、`.v2.bak` 或 `.v3.bak`。旧应用拒绝新版本；备份文件用于追溯旧状态，不会包含升级后的新对话内容。未来版本同样拒绝覆盖。

执行检查点使用 v1/v2；实际采用并行后写 v2，并记录已启动的调用范围。不可安全重试、结果未知的外部写操作保持待人工处理，不自动重复执行。全量备份包含学习观察、解释复核、项目文件与 Git 历史；恢复到新目录后清除会话授权、MCP 启用状态及项目选择。

macOS Apple Silicon 本地安装器为 `desktop/release/Zhixing-0.5.0-mac-arm64.dmg`，运行环境内附。项目 Git 操作需要系统 Git，配置 MCP 服务需要该服务对应的可执行程序。当前为未签名、公证的本地预览；Windows/Intel Mac 的流水线配置不等于实机验收。源码和安装器不会自动替换用户现有应用；本轮没有正式发布或自动推送。

完整验证结果、真实合成请求与平台待验项见 [P1/P2 验收记录](evidence/agent-p1-p2-20260907.md)。
