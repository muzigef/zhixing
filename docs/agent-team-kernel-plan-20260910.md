## 目标与约束

单 Agent、同模型团队、异模型团队共用 AgentService、受控工具执行、权限、记忆、模型绑定及资源预算。团队成员应拥有可持续的独立任务上下文，主 Agent 可以安排依赖、根据证据追加工作并补做失败阶段。用户看到执行进度、核查覆盖和未解决问题；模型意见不冒充工具或事实验证。

本轮不更换框架、不自动扩大模型费用/并发上限、不开放成员越权写入。已授权只读工具足以先实现独立检索和核查；三种模式仍由用户选择。真实教学成效、系统钥匙串授权和安装交付分别验收，不能用单元测试代替。
