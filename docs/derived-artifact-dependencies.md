# 派生产物依赖与失效

2026-09-18。失效是停止将旧结果作为当前依据；原文、历史产物与评测记录保留，不自动删除用户材料。

| 产物 | 依赖与复用条件 | 不匹配时 |
| --- | --- | --- |
| 会话摘要 | 连续原消息哈希、summaryRecipe、摘要内容哈希；记录配置的生成 Provider/模型 | 停止注入旧摘要，从原文重新整理；保留用户锚点和完整历史 |
| 文档索引及部分 OCR 复用 | 原始文件 SHA256、结构切块规则与 PDF/逐页 OCR 策略版本 | 下一次显式导入重新提取及切块；不复用旧策略 OCR 片段 |
| 语义向量 | 片段内容哈希、文档索引 recipe、嵌入模型身份、语义处理 recipe | 旧记录不匹配，新建对应索引；查询/构建异步返回后再次核对来源，变化即拒绝 |
| 本机 Ollama 嵌入 | 上述条件以及实际 digest，请求前后核对 | 模型变化拒绝当前结果 |
| 实践验证 | 已有实现和测试脚本内容哈希 | 旧通过记录不再作为当前通过证据 |
| 团队任务包/恢复 | 已有任务包内容、权限、配置和模型绑定 | 拒绝跨配置/范围继续复用 |
| 构建与评测 | 实际受控源码文件哈希 | 按构建区分；Python `__pycache__` 不污染源码身份 |

这些是具体依赖链，不是所有历史结论自动重算。生成模型字段是配置身份，远端同名模型内部升级无法据此检测。摘要换 Provider 不会自动失效，因为其用途是历史衔接；更改生成规则必须提升 recipe。OCR 策略标记也不声称核验了本机 Tesseract/Poppler 二进制版本，升级外部识别引擎需要显式复核资料。

旧语义索引与旧摘要不会被静默赋予新版本。资料需显式重新导入，语义索引需重新建立；既有词法查询可继续使用已导入片段，并保留其来源版本信息。

测试：`derived-artifact-dependencies.test.ts`、`summary-coverage.test.ts`、`pdf-page-ocr.test.ts`；后两者通过共享 Runtime 与实际 PDF 导入路径验证。
