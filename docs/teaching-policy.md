# 基于实际作答的教学建议

知识检查的新提交按题目记录知识点、目录版本、答对与否及帮助方式，来源可定位到检查 ID、题目序号和记录修订。四个内置主题的前三个学习日共映射 24 个知识点。定制课程没有作者提供的对应题目时，仍明确显示检查不可用；旧记录只有总分时，不反推各知识点是否答对。

在获准使用学习上下文的会话中，相关问题可获得有来源的教学建议；CLI 与桌面共用 TeachingPolicy。选择以知识点中英文别名和明确的复习/进度请求为依据，不因一句话含“我”就调入旧作答。模型还可用只读 `learning_state(question)` 查询未提供的记录。

| 最近相关记录 | 默认建议 |
| --- | --- |
| 对应题目答错 | 正例和反例对照，说明具体错误边界 |
| 使用提示/参考答案答对、帮助未记录或存在用户更正 | 补充讲解，按意愿提供引导练习 |
| 自报独立答对 | 可选同知识点新情境，检查迁移 |
| 没有对应题目证据 | 正常解释，不推断学习水平 |

用户本轮要求优先。明确要答案或完整推导时直接完成讲解，要求仅提示时不先给答案；没有明确要求互动教学时，不用“确认后继续”打断回答。这些是程序生成的建议及提示契约，真实模型遵循质量仍需要评估，不能仅凭规则宣称教学效果提高。

更正内容和版本随来源进入新建议。撤回后不参与新的建议；历史作答和已发送对话保留。建议不改变课程完成状态、不授予工具权限、不把帮助自报当作独立验证，不读取尚未完成的学习效果试验答案。
