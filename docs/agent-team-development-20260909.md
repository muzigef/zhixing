## 评测设计

冻结测试题、自动正确性规则和执行参数后运行同一题目集：普通单 Agent、允许额外自检的单 Agent、同模型团队、异模型团队。补充每家参与模型的单 Agent 基线，避免误把主模型更强当作团队收益。所有失败/超时/不完整回答保留并计入分母。

开发题用于修复；留出题不据单个结果调整提示。覆盖数学条件、算法/代码正确性、资料约束、教学解释与简单串行问题。使用确定答案、可执行校验及明确的评分点；开放回答的自动检查与开发助手复核不等于独立人类盲评或真实教学效果。记录实际参与模型、请求数、已报告输入/输出/缓存用量、缺失用量、首字和总耗时；订阅消耗不当作零成本。

先用有界工程样本确认真实通路，再跑重复配对对照；比较质量与实际资源开销，并明确同上限不等于同算力。若差异不足或团队退化，保留真实结果并将团队标为实验性，不宣称“优于单 Agent”。
