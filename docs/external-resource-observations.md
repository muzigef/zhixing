# 外部版本观测与防循环

2026-09-18。MCP 只读且 replaySafe 的工具可以配置 `observation: { identity: "id", resultIdentity: "id", version: "revision" }`。这些字段明确指定请求资源身份、响应身份和版本；只接收非错误 structuredContent 中身份精确一致、有界字符串/整数版本。

应用在 ToolHarness 产生独立的资源/版本哈希回执，与完整输出、执行前 toolState 一同保存。防循环从持久执行日志恢复最新观测，并按本次工具参数对应的资源过滤：其他对象版本变化不能解除当前对象的重复限制。响应正文、任意时间戳、成功口吻、缺失/畸形版本均不替代配置的版本字段。取消后未保存的观察不作为进展。

初次观测建立状态，因此第一次查询后可在已知版本下再读一次；在同版本同参数下继续重复会停止。通过另一种有意义查询观测到同资源新版本，原查询才可重新进行；总轮次、工具次数、时间和预算上限保持不变。恢复同样使用执行时已保存的状态，不能因重启清空防循环。

这不是外部变化订阅：只有真的执行获准查询才可能知道新版本。服务给出版本仍是服务声明，不能证明真实世界变化或内容正确。未配置观察契约的工具保持原有本地操作/成功写入状态规则。

验证包含实际 AgentService→惰性发现→MCP 本地进程→执行日志→LoopGuard，分别验证版本稳定时停止、观测到新版本后继续；另外验证错误/身份错配/普通文本不记版本、其他资源不解锁和 JSON 重载保持状态。
